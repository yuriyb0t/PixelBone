# PixRig

[English](README.md) | **Русский**

Расширение для [Aseprite](https://www.aseprite.org/) на Lua для 2D-скелетной анимации.

PixRig позволяет создать 2D-скелет, сгенерировать «кожу» — силуэт из капсул — и экспортировать позы или анимацию в спрайт Aseprite отдельными слоями.

> **Ранняя стадия разработки — версия 0.3.0**
>
> Редактирование скелета, генерация кожи и экспорт одной позы слоями проверены в Aseprite. Редактирование анимации и экспорт анимации реализованы, но **ещё не проверены в Aseprite**. IK и импорт 3D-анимации запланированы.

## Цели

Текущая задача — удобный workflow 2D-риггинга и пиксельной анимации внутри Aseprite.

Долгосрочная цель — импорт 3D-анимации из **GLB/glTF или BVH**, ретаргет рига **Mixamo** на 2D-скелет и превращение результата в пиксельную анимацию.

Отложенная возможность — **«умные кости»**, как в Moho: художник рисует крайние позы, а угол кости управляет деформацией пикселей.

## Текущий статус

| Этап | Возможности | Статус |
| --- | --- | --- |
| 1 | Холст с костями: Create / Edit / Link / Delete, зеркало, Undo / Redo, хранение в `sprite.data` | Работает; проверено в Aseprite |

## Установка

### Требования и совместимость

- Aseprite для Windows с поддержкой расширений на Lua.
- Проверенная версия среды разработки — **Aseprite 1.3-rc4-dev**. Другие сборки могут вести себя иначе; функции анимации ещё требуют проверки.
- Для кожи и экспорта слоями используйте спрайт в режиме **RGB**.
- Lua и Python **не нужны для установки готового расширения**. Они нужны только для необязательных тестов и сборки из исходников.

### Установка готового расширения

1. Получите файл `pixrig-<version>.aseprite-extension`: скачайте его со страницы **Releases** репозитория, если пакет там опубликован, либо соберите из исходников по инструкции ниже.
2. Закройте открытые окна PixRig.
3. В Aseprite откройте **Edit → Preferences → Extensions**.
4. Если установлена старая версия PixRig, сначала выделите её и нажмите **Uninstall**.
5. Нажмите **Add Extension**, выберите файл `.aseprite-extension` и подтвердите добавление.
6. **Перезапустите Aseprite**, чтобы завершить установку и загрузить новую версию.
7. Откройте RGB-спрайт и запустите **File → PixRig...**.

**Важно:**

- Выбирайте готовый файл `.aseprite-extension` через **Add Extension**. Распаковывать его или переименовывать в `.zip` не нужно.
- **Не** копируйте пакет или распакованные исходники напрямую в папку `extensions` Aseprite.
- Перед установкой новой версии удалите старую, затем перезапустите Aseprite.

### Обновление

Повторите установку: удалите PixRig через **Preferences → Extensions**, добавьте новый пакет и перезапустите Aseprite.

### Удаление

Откройте **Edit → Preferences → Extensions**, выделите PixRig, нажмите **Uninstall** и перезапустите Aseprite.

Удаление расширения не удаляет слои и cel'ы, которые уже были экспортированы в спрайт.

## Сборка из исходников

Выполните команду из корня репозитория:

```sh
python3 build.py
```

Если в Windows используется Python Launcher:

```powershell
py -3 build.py
```

Скрипт сборки объединяет Lua-модули в `dist/main.lua` и создаёт пакет:

```text
dist/pixrig-<version>.aseprite-extension
```

Установите полученный пакет по инструкции выше. Скрипт сборки — **только бандлер**: он не устанавливает расширение в Aseprite и не проверяет его работу во время выполнения.

## Запуск тестов логики

Для тестов чистой Lua-модели нужен **Lua 5.3 или 5.4**, доступный в PATH под именем `lua`.

Из корня репозитория:

```sh
lua tests/test_rig.lua
```

Тесты проверяют логику вне API Aseprite. Успешное прохождение тестов **не подтверждает** работу диалогов, ввода на холсте, таймеров, изменения спрайта или экспорта анимации. Эти возможности нужно проверять вручную в Aseprite.

## Структура проекта

```text
pixrig/
  rig.lua       Модель скелета, радиусы, группы, зеркало, анимации, FK-позы
  skin.lua      Растеризация кожи: капсулы, радиусы суставов, контур
  export.lua    Запись в спрайт: одна поза и вся анимация
  ui.lua        Основной диалог и окно PixRig Timeline
  store.lua     Сохранение в sprite.data
  json.lua      Мини-JSON
  view.lua      Зум и панорамирование холста
entry.lua       Команда File > PixRig... и показ полной ошибки
build.py        Сборка в один файл и упаковка расширения
tests/
  test_rig.lua  Тесты логики на чистом Lua
PROJECT.md      Технический паспорт проекта на английском
PROJECT.ru.md   Технический паспорт проекта на русском
```

Модель, растеризация кожи, JSON, хранение и вид отделены от операций рендеринга и экспорта через API Aseprite. `rig.lua` и `skin.lua` написаны на чистом Lua и не используют API Aseprite.

## Как это работает

- Кости и настройки рига хранятся в JSON в `sprite.data` спрайта, под ключом `pixrig`.
- Кожа генерируется из капсул с настраиваемыми радиусами суставов.
- Группы кожи имеют собственные цвета и экспортируются отдельными слоями.
- Позы рассчитываются через прямую кинематику относительно rest-позы.
- Экспорт перестраивает только выделенную группу слоёв **PixRig**. Пользовательские слои не изменяются; слои внутри сгенерированной группы заблокированы.

## Подход к разработке

PixRig — расширение для Aseprite, а не отдельный редактор и не форк. Возможности Bonebase рассматриваются как ориентир по функциям, но не как источник кода для копирования. Сначала планируется паритет по возможностям, затем — деформация через «умные кости».
