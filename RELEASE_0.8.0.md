# PixelBone v0.8.0 — Assembly Pose, Bone Inspector, Layered Artwork

**Дата:** 27 ноября 2026 года  
**Статус:** исходники собраны; синтаксис Lua и автоматические тесты пройдены; **в реальном Aseprite запуск не выполнялся**.

## Главное изменение: Rest → Assemble → Animate

В версии 0.8.0 введено отдельное положение **Assembly Pose**, которое не является кадром анимации.

- **Rest** — исходные координаты костей и разнесённые детали на Paint Sheet. Здесь рисуем кости, меняем радиусы, устанавливаем родителя. Исходные пиксели не двигаются при сборке.
- **Assemble** (на узком окне — **Build**) — собираем детали в персонажа, используя **Move** и **Rotate**. Эти изменения сохраняются как независимые смещения каждой кости и **не создают ключей**.
- **Animate** (в компактном режиме **Anim**) — анимируем собранного персонажа. `Rotate`, `Move`, Timeline, Play/Stop, ключи, Copy/Paste Pose по-прежнему используют анимационный движок.

Пример: на Paint Sheet рука нарисована в правой части спрайта. В Rest это положение остаётся неизменным. В Assemble через Move переносим руку к плечу. В Animate уже на **кадре 1** рука находится на месте, и дальнейшая анимация работает относительно этой сборки.

### Как проверить базовый пайплайн

1. Сделайте **копию** проекта `.aseprite` с PixelBone v0.7.0.
2. Установите v0.8.0, откройте копию спрайта. Скелет/анимации должны загрузиться из `sprite.data.pixrig` без преобразования формата.
3. Перейдите в **Rest** и создайте две или больше разнесённых костей/деталей. При назначении родителя для разнесённых частей используйте **Disconnected** (Change Parent или Link на тело кости, не на конец).
4. Откройте **Paint** → **Generate new Paint Sheet** → **Open Paint Sheet in Aseprite**; раскрасьте детали в стандартном редакторе Aseprite.
5. Перейдите в **Assemble** → **Move**, переместите разнесённые элементы к телу; при необходимости **Rotate**. Никаких дополнительных «сборочных» ключевых кадров не требуется.
6. В **Animate** перейдите на кадр **1** и проверьте, что персонаж уже собран. Поверните конечность через **Rotate** — ключ появится только здесь. Изменения Assemble должны распространяться на все кадры без переписывания старых ключей.
7. Для шляпы: выберите кость головы в Canvas или Timeline → **Paint** → **New layer for selected bone...** → назовите слой `Hat`. Aseprite создаст редактируемый `Hat [bone N]` в активном Paint Sheet. Нарисуйте шляпу **на первом кадре** этого слоя, в любом месте Paint Sheet — пиксели этого слоя будут привязаны именно к выбранной кости. Убедитесь, что деталь появляется на анимированном персонаже и следует за головой при повороте на других кадрах.
8. Нажмите **More** → **Export animation to layers** для проверки экспорта. Экспорт, как и в предыдущих версиях, заменяет только генерируемую группу `PixRig`; **оригинальные Paint Sheets сохраняются**.

## Новый Bone Inspector

Во вкладке **Bone** после выбора кости показываются:

- название и цифровой ID выбранной кости;
- **Parent:** имя и ID родительской кости либо `None (root)`;
- **Connection:** `Connected` или `Disconnected`;
- **Children:** число детей и кнопки выбора первых пяти дочерних костей;
- `Select Parent`, `Change Parent`, `Connect/Disconnect`, `Unparent`;
- текущие параметры Assembly: вращение и X/Y-перемещение; `Edit Assembly` и `Reset this bone`.

`Change Parent` принимает **ID** или точное **имя** кости. В целях безопасности он устанавливает связь `Disconnected`, не перемещая исходное рисование. `Connect` сознательно переместит точку начала дочерней кости к концу родительской **в Rest**; выполните это до раскраски либо на копии проекта.

**Rotate** и **Move** теперь отдельные явные кнопки в верхней панели. Выбранный инструмент сохраняет Assemble, если вы находитесь в этом режиме. При переключении в Animate активируется Rotate. IK по-прежнему работает в Animate.

## Многослойный Paint Sheet и синхронизация

Новый `binding.lua` обрабатывает **несколько редактируемых слоёв** текущего Paint Sheet без перезаписи исходных cel-изображений:

- `Body [bone group 1]` — обычная автоматическая привязка пикселей к ближайшей кости группы 1.
- `Hat [bone 12]` — **явная привязка** всех пикселей слоя к кости ID 12, независимо от их близости к другим костям. Для создания такого слоя есть кнопка `New layer for selected bone...`.
- `Accessories [bone group 1]` — группа слоёв, внутри которой можно добавлять обычные вложенные слои с именами без тега. Они унаследуют номер группы для Auto Bone Binding.

Поддержаны видимость и прозрачность слоёв/cel. Перечитывается **первый кадр** исходного Paint Sheet. Изменения в Aseprite и Undo/Redo помечают предпросмотр для обновления через `sprite.events`. Есть ручная кнопка **Refresh artwork**. Новые изображения применяются в **любом анимационном кадре** без изменения ключей.

Если в спрайте несколько поколений `PixRig Paint Sheet...`, **активным считается последний (обычно самый новый)**. `Open Paint Sheet` открывает именно его; несколько поколений одновременно не смешиваются.

## Архитектура и совместимость

- Одно главное окно: вкладки и редактируемый Paint Sheet слева, Canvas и Timeline справа; старый **Classic UI** включён как резервный режим.
- Остался существующий объектный формат `sprite.data.pixrig`, `version = 2`. Добавлено только **необязательное** поле `assembly` со смещениями `{rot,dx,dy}` по ID кости. Старые проекты без этого поля загружаются с нулевыми смещениями. Новые данные требуют v0.8.0 для корректного учёта Assembly при анимации.
- Движок сохраняет прежние ключи, IK-цепочки и экспорт. Во время расчёта позы к каналам кадров прибавляются независимые Assembly-смещения.
- Оригинальные слои, изображения и cel не перезаписываются при привязке и сборке. Генерация новых Paint Sheets по-прежнему не удаляет старые; при экспорте пересоздаётся только служебная группа `PixRig`.
- Собственный пиксельный редактор внутри окна не реализован: используются Pencil, Eraser, Color Picker и Aseprite Undo/Redo.
- Минимальная версия Aseprite **не повышена** относительно v0.7.0: ориентир — Aseprite 1.3-rc4-dev, уже использовавшаяся в проекте. Однако новая многослойная обработка требует **практической проверки** на конкретной установленной сборке.

### Изменённые или добавленные файлы относительно v0.7.0

- `pixrig/rig.lua` — необязательная Assembly Pose, хранение, Undo, объединение сборки с анимацией, начальная позиция IK-контроллеров.
- `pixrig/binding.lua` — многослойные исходники, явный Bone ID, compositing, выбор актуального Paint Sheet.
- `pixrig/paint.lua` — создание дополнительного Paint Sheet-слоя для выбранной кости.
- `pixrig/ui.lua` — режимы Rest/Assemble/Animate, Rotate/Move, Bone Inspector, новые кнопки Paint, синхронизация активного Paint Sheet.
- `entry.lua`, `package.json` — версия и команда PixelBone 0.8.0.
- `tests/test_assembly.lua`, `tests/test_art_layers.lua` — новые модульные сценарии.
- `tests/harness_workspace.lua`, `tests/harness_bundle.lua` — обновлённые UI-сценарии, в том числе Assemble и дополнительные слои.
- `SOURCE_README.txt`, `PROJECT.md`, `RELEASE_0.8.0.md` — документация.

Без изменений алгоритмов: `pixrig/skin.lua`, `pixrig/export.lua`, `pixrig/json.lua`, `pixrig/store.lua`, `pixrig/view.lua`, `pixrig/ui_classic.lua`, `pixrig/templates.lua`; старые модульные тесты сохраняются.

## Выполненные автоматические проверки

Среда: Lua, совместимый с 5.3 (`texlua` / `texluac`) и имитация API Aseprite. **Настоящий экземпляр Aseprite не запускался**.

```sh
python3 build.py
texluac -p pixrig/*.lua entry.lua dist/main.lua
texlua tests/test_rig.lua
texlua tests/test_templates.lua
texlua tests/test_assembly.lua
texlua tests/test_art_layers.lua
texlua tests/harness_workspace.lua
texlua tests/harness_classic.lua
texlua tests/harness_bundle.lua
for spec in '1366 768 1' '1920 1080 1' '1366 768 2' '1920 1080 2'; do
    set -- $spec
    SCREEN_W=$1 SCREEN_H=$2 UI_SCALE=$3 texlua tests/harness_sizes.lua
done
```

Проверены сценарии: создание костей, Assembly без ключей, исходная поза отдельно от сборки, применение Assembly ко всем кадрам, сохранение/загрузка данных, Undo, экспрессия дополнительных слоёв, явная привязка к Bone ID, видимость/прозрачность, переключение вкладок и режимов, работа Timeline, Paint Sheet, создание/удаление IK, старый Classic UI, структура собранного скрипта и размеры интерфейса для нескольких разрешений. **Это тесты логики и имитация Aseprite — не доказательство реальной совместимости интерфейса**.

## Что ещё проверить вручную и известные ограничения

1. Открытие/закрытие окна, работа событий и координат мыши в реальной **Aseprite 1.3-rc4-dev**.
2. Переключение между Aseprite и PixelBone при рисовании, стирании, перемещении cel и Undo/Redo, особенно при живом обновлении вложенных слоёв и прозрачности.
3. Базовый экспорт в спрайт, продолжительность кадров, повторный экспорт и настоящая Aseprite Undo/Redo экспортированных слоёв.
4. **IK требует связанную (`Connected`) цепь в Rest**. Для конечностей, нарисованных далеко друг от друга в Disconnected, сначала нужно подготовить корректную цепь. Комбинации сложной Assembly/IK могут потребовать доработки.
5. **Rest и Assembly по-прежнему используют одну систему bone ID и исходных координат**, поэтому изменения костей в Rest после покраски могут изменить Auto Bone Binding для слоёв с `[bone group N]`. Для аксессуаров `[bone N]` привязка надёжнее, но старый рисунок на месте физически не перемещается.
6. Поддерживаются только пиксели **первого кадра** редактируемого источника; анимированные источники с разными cel пока не поддержаны.
7. Панели нельзя перетаскивать для изменения их ширины. На 1366×768 с 200% UI некоторые необязательные кнопки переключения видимости доступны через вкладку More, а не в верхней строке. Размеры проверены математически, не на дисплее.
8. Перемещение кости в режиме `Edit` меняет Rest и может сдвинуть раскрашенные детали относительно их привязки. Для сборки используйте **Assemble + Move**.
9. Старый Classic UI предназначен для **диагностики и работы со старыми проектами**. Он загружает данные, но не имеет отдельного редактора Assembly Pose. Изменять Assembly-проект предпочтительно в новой версии.
10. Библиотека Poses остаётся временной для текущего сеанса, как в v0.7.0.

## Установка

1. Сделайте резервную копию исходного `.aseprite` проекта.
2. В Aseprite: **Edit → Preferences → Extensions → Add Extension** → `PixelBone_v0.8.0.aseprite-extension`.
3. При необходимости перезапустите Aseprite; откройте спрайт и запустите **File → Scripts → PixelBone 0.8.0...**.
4. При установке рядом с предыдущей сборкой того же расширения обновите/замените её через настройки, а не держите одновременно две версии `pixelbone`.
5. Для сборки из исходников: `python3 build.py` — получится файл `dist/pixelbone-0.8.0.aseprite-extension`.
